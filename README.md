# Hollow Snow

A third-person shooter set in a frozen, fog-bound forest, with all models and textures generated in code. Light the three wardfires, reach the altar and defeat the Hollow King.

Open `index.html` in a desktop browser to play. An internet connection is needed because Three.js loads from a CDN. Choose a skin and weapon on the title screen or in the pause menu. The Character room on the title screen lets you orbit and zoom around the character to inspect it.

| Input | Action |
| --- | --- |
| WASD | Move |
| Mouse | Look |
| Left click | Fire |
| Right click | Aim |
| R | Reload |
| 1-5 | Switch weapon |
| Shift | Sprint |
| Space | Dodge |
| E | Hold to interact |
| M | Mute |
| P or Esc | Pause |
